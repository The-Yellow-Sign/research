# Микросервис аутентификации

Этот микросервис отвечает за проверку учетных данных пользователей и выдачу JWT‑токенов. Он реализован на **Go** и использует **PostgreSQL** для хранения хешей паролей. При запросе `/login` сервис:
1. Принимает `username` и `password`.
2. Хеширует пароль с помощью **bcrypt** и сравнивает с записью в базе.
3. При совпадении генерирует JWT, подписанный RSA‑ключом, и возвращает клиенту.
4. Токен содержит `sub`, `iat`, `exp` и роли пользователя.

### Ключевые особенности
- **Rate limiting** через `golang.org/x/time/rate` – защита от перебора.
- **Refresh token** endpoint `/refresh` для продления срока действия без повторного ввода пароля.
- **Audit log** записывается в Kafka (`auth-events` topic) для последующего анализа.

### Как использовать
```bash
curl -X POST https://auth.example.com/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"s3cr3t"}'
```
Полученный токен передаётся в заголовке `Authorization: Bearer <token>` к другим микросервисам.
