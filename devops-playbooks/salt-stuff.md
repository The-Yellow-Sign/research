## Список изменений: Обновление конфигураций SaltStack v2024.12

Данное обновление содержит новые стейты (states) для настройки безопасности серверов.

### Что нового
- **SSH State**: Добавлена автоматическая ротация ключей хоста.
- **Firewall**: Новый модуль для управления `nftables` (взамен `iptables`).
- **Nginx**: Теперь поддерживает автоматическую установку модуля Brotli.

### Исправления
- Исправлена ошибка в стейте `docker-install`, которая приводила к сбою на Ubuntu 24.04.
- Улучшена обработка шаблонов Jinja.

### Инструкция по применению
Запустите `state.highstate` на тестовой группе серверов:

```bash
salt 'test-server-*' state.highstate
```

> [!IMPORTANT]
> Это промежуточное обновление. Полная документация стейтов находится во внутреннем Wiki.
