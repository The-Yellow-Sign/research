# Security Advisory: Неавторизованный доступ к Redis

## Описание
В некоторых конфигурациях Redis был запущен без включенной аутентификации и привязки к локальному интерфейсу (`127.0.0.1`), что позволяет любому пользователю в сети получить полный доступ к данным.

## Решение
Необходимо внести изменения в `redis.conf` на всех инстансах.

### 1. Настройка привязки и пароля
```text
# /etc/redis/redis.conf
bind 127.0.0.1
protected-mode yes
requirepass "ваш_очень_длинный_пароль"
```

### 2. Применение изменений
```bash
systemctl restart redis
```

> [!NOTE]
> Если Redis используется в Docker, убедитесь, что порты не выставлены наружу (`0.0.0.0:6379`).

## Проверка
Попробуйте подключиться без пароля:
```bash
redis-cli ping
```
Если вы получили `(error) NOAUTH Authentication required.`, значит защита работает.
