# Документация API сервиса управления инвентарем (FastAPI)

Этот микросервис обеспечивает учет товаров на складах и интеграцию с ERP системой.

## Основные эндпоинты

| Метод | Путь | Описание | Auth |
| :--- | :--- | :--- | :--- |
| `GET` | `/v1/items/` | Список всех товаров | ✅ |
| `POST` | `/v1/items/` | Создание нового товара | ❌ |
| `GET` | `/v1/items/{id}` | Детальная информация | ✅ |
| `DELETE`| `/v1/items/{id}` | Удаление (архивация) | ❌ |

## Структуры данных

### Тело запроса (Create Item)
```json
{
  "name": "Ноутбук Apple MacBook Pro 14",
  "sku": "MAC-14-M3-16-512",
  "quantity": 10,
  "price": 199990.00,
  "tags": ["electronics", "apple", "laptop"]
}
```

### Пример ответа
```json
{
  "status": "success",
  "data": {
    "id": "item_9921",
    "created_at": "2024-12-29T18:15:00Z"
  }
}
```

## Обработка ошибок
FastAPI автоматически генерирует 422 Unprocessable Entity, если входящий JSON не соответствует схеме Pydantic.

> ⚠️ NOTE: Документация в формате Swagger доступна по адресу `/docs`, а ReDoc — по адресу `/redoc`.
