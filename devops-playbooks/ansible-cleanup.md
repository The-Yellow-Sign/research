## Быстрая очистка диска на удаленных серверах через Ansible

Данный ранбук используется при критическом алерте `DiskSpaceLow` (>95%), когда ручная очистка занимает слишком много времени.

### Шаг 1: Запуск очистки логов
Эта команда находит и обнуляет все файлы `.log` старше 7 дней в `/var/log`.

```bash
ansible all -m shell -a "find /var/log -type f -name '*.log' -mtime +7 -exec truncate -s 0 {} \;" -i inventory.ini --become
```

### Шаг 2: Очистка Docker ресурсов
Если на сервере запущен Docker, он часто является причиной нехватки места из-за старых слоев и образов.

```bash
ansible web_servers -m shell -a "docker system prune -af" -i inventory.ini --become
```

### Шаг 3: Проверка результата
Проверьте свободное место на всех узлах после выполнения:

```bash
ansible all -m shell -a "df -h /" -i inventory.ini
```

### Меры предосторожности
- По умолчанию ранбук не трогает системные дампы в `/var/crash`.
- > ⚠️ WARNING: Команда `docker system prune -af` удалит ВСЕ неиспользуемые образы. Убедитесь, что критические образы не помечены как "dangling".
