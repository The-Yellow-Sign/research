# Payment Service API (v2)

Данный сервис интегрирован с Stripe и обеспечивает проведение транзакций.

## Эндпоинты

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `POST` | `/v2/charge` | Создание нового платежа |
| `GET`  | `/v2/history`| История транзакций юзера |
| `POST` | `/v2/webhook`| Колбэк от Stripe |

## Примеры запросов

### Создание платежа
```json
{
  "amount": 5000,
  "currency": "usd",
  "source": "tok_visa",
  "description": "Оплата подписки"
}
```

### Формат ошибки (JSON)
```json
{
  "error": {
    "code": "card_declined",
    "message": "Ваша карта была отклонена."
  }
}
```

> [!NOTE]
> Все запросы требуют наличия заголовка `X-API-Key`. Получить ключ можно в [админ-панели](inventory-api-docs.md).
