# Чейнджлог обновления модулей Terraform для работы с AWS (v4.0.0)

Это мажорное обновление, которое включает в себя ломающие изменения (breaking changes). Пожалуйста, внимательно прочитайте перед обновлением `terraform { required_version = "..." }`.

### ГЛАВНЫЕ ИЗМЕНЕНИЯ (Breaking Changes)
- **S3 Bucket**: Модуль теперь по умолчанию включает Public Access Block. Если ваши бакеты должны быть публичными, добавьте флаг `force_public = true`.
- **RDS Module**: Изменено имя переменной с `db_username` на `master_username`.
- **EKS**: Переход на использование `managed_node_groups` стал обязательным.

### Новые фичи
- Добавлена поддержка IPv6 для модулей VPC.
- Обновлен провайдер AWS до версии 5.x.
- Добавлена автоматическая маркировка (tagging) всех ресурсов.

### Порядок обновления
1. Измените версии модулей в вашем коде.
2. Запустите `terraform init -upgrade`.
3. Сделайте `terraform plan`, чтобы убедиться, что изменения в ресурсах соответствуют вашим ожиданиям.

### Примеры кода
```hcl
module "s3_bucket" {
  source = "github.com/myorg/tf-s3-module?ref=v4.0.0"
  bucket_name = "my-secure-data"
  # force_public = false // Новое поведение по умолчанию
}
```
