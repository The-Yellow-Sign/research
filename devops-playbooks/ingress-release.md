# Список изменений для Nginx Ingress Controller

### Новое в версии 1.9.0
- **Chroot**: Добавлена поддержка запуска Nginx в chroot среде для повышения безопасности.
- **Lua**: Обновлен модуль Lua для улучшения производительности обработки правил.
- **Metrics**: Добавлены новые метрики для отслеживания задержек апстримов.

### Улучшения
- Оптимизирован процесс перезагрузки (reload) конфига при большом количестве Ingress-ресурсов.
- Улучшена обработка SSL-сертификатов.

### Исправления
- Исправлена утечка памяти при частых изменениях Endpoint-ов.
- Исправлен баг с дублированием заголовков.

### Как обновиться?
```bash
helm upgrade ingress-nginx ingress-nginx/ingress-nginx --version 4.8.0
```
