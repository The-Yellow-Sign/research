# Оптимизация Java (JVM) в Docker-контейнерах

При запуске Java в контейнерах часто возникают проблемы с лимитами памяти и CPU из-за того, что JVM "видит" ресурсы хоста, а не контейнера.

### Память и Cgroups
Для современных версий Java (8u191+, 11+) используйте флаги, которые делают JVM "Cgroup aware".

```bash
# Использование процентного соотношения к лимиту контейнера
java -XX:MaxRAMPercentage=75.0 -jar app.jar
```

### CPU Лимиты
Если вы ограничиваете CPU (`--cpus="2.0"`), убедитесь, что JVM корректно определяет количество потоков для ForkJoinPool.

```bash
java -XX:ActiveProcessorCount=2 -jar app.jar
```

### Сжатие Heap
Для экономии памяти в небольших сервисах (микросервисах):

```bash
-XX:+UseSerialGC # Если CPU всего 1 ядро
-XX:MaxHeapFreeRatio=20
-XX:MinHeapFreeRatio=10
```

> [!TIP]
> Всегда используйте `distroless` или `alpine` образы для уменьшения поверхности атаки и размера образа.
