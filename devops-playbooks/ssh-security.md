# Отключение SSH Root Login и переход на SSH-ключи

## Описание
Использование пароля для пользователя `root` по SSH является критической уязвимостью. Рекомендуется разрешать вход только по ключам и только для обычных пользователей с последующим использованием `sudo`.

## Исправление
Отредактируйте файл `/etc/ssh/sshd_config` на всех серверах Linux.

```text
# Запрет входа root
PermitRootLogin no

# Запрет входа по паролю
PasswordAuthentication no

# Разрешение только конкретных групп (опционально)
AllowGroups ssh-users
```

## Применение
Перед перезапуском службы убедитесь, что вы добавили свой публичный ключ в `~/.ssh/authorized_keys` вашего пользователя!

```bash
sshd -t
systemctl restart sshd
```

> [!NOTE]
> Если вы заблокируете себе доступ, используйте VNC/IPMI консоль провайдера для восстановления конфигурации.
