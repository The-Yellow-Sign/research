## Создание и восстановление резервных копий PostgreSQL

Данный ранбук описывает процедуру регулярного бэкапа и экстренного восстановления базы данных PostgreSQL.

### Шаг 1: Создание дампа (Logical Backup)
Для небольших и средних БД (до 100GB) используйте `pg_dump`.

```bash
# Создание сжатого дампа конкретной базы
pg_dump -h localhost -U postgres -d my_database -F c -f /backups/my_database_$(date +%Y%m%d).dump
```

> [!WARNING]
> Регулярно проверяйте наличие свободного места в директории `/backups`, так как процесс может завершиться с ошибкой `Disk full` без уведомления.

### Шаг 2: Восстановление из дампа
Перед восстановлением убедитесь, что база данных уже создана или используйте флаг `--create`.

```bash
# Восстановление в новую базу
pg_restore -h localhost -U postgres -d my_database_new -v /backups/my_database_20241225.dump
```

### Шаг 3: Проверка целостности
После восстановления запустите базовые проверки:

1. Проверьте количество таблиц: `\dt` в psql.
2. Проверьте размер базы: `SELECT pg_size_pretty(pg_database_size('my_database_new'));`

> [!IMPORTANT]
> Для высоконагруженных систем (High Load) используйте физический бэкап через [Wal-G](https://github.com/wal-g/wal-g) или `pg_backrest`.
