## Обновление Ansible Role: Redis v2.5.0

Данное обновление добавляет поддержку Redis Enterprise и улучшает стабильность Sentinel.

### Что нового
- Добавлена поддержка развертывания в Ubuntu 24.04.
- **Sentinel**: Теперь можно настраивать `failover-timeout` через переменные.
- **Security**: Автоматическая генерация сильных паролей, если они не указаны.

### Исправления
- FIXME: Исправлен баг, когда конфигурация не обновлялась при рестарте сервиса.
- TODO: Добавить поддержку ACL для Redis 6+.

### Пример использования
```yaml
- hosts: redis_nodes
  roles:
    - role: redis
      vars:
        redis_version: "7.2"
        redis_sentinel: true
```

> [!IMPORTANT]
> Это мажорное обновление. Перед запуском на проде убедитесь, что вы обновили `requirements.yml`.
